# AI Context Router

Read `README.md` and `ai/01-current-state.md` first. If this is a continuation, also read `ai/handoff.md`. Then open only the feature docs required by the task.

## Routes

- Product/architecture decisions: `ai/02-decisions.md`
- Domain and pipeline vocabulary: `ai/03-glossary.md`
- Fetch/sync: `ai/features/fetch-sync.md`
- Parsing, keywords and schemas: `ai/features/parsing-keywords.md`
- Event candidate generation: `ai/features/clustering.md`
- Optional model-assisted event verification: `ai/features/llm-event-verification.md`
- Exact contract/outcome matching: `ai/features/contract-matching.md`
- Live scanner, calculation and FastAPI: `ai/features/arbitrage-api.md`
- Data contracts: `ai/features/data-schemas.md`
- Commands, checks and Git: `ai/features/operations.md`

There is no archive or historical-plan directory. Obsolete duplicated context was deleted so agents do not mistake old plans for the current product direction.
